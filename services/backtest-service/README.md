# Backtest Service

Детерминированный offline replay на сохранённых закрытых свечах. Использует тот же `AnalysisPipeline`, `AlgorithmEngine` и входные JSON-конфигурации, что live SMC Service.

- сигналы доступны только после закрытия породившей свечи;
- вход проверяется на последующих свечах;
- риск фиксирован настройкой `risk_per_trade_percent`;
- учитываются комиссия, slippage, funding, gap, частичные цели, безубыток и ликвидация;
- при одновременном SL/TP используется консервативный приоритет Stop Loss;
- ML, локальное переобучение и model artifacts отсутствуют.

В ответе временно сохранён ключ `scenarios`, необходимый существующему фронту графика. Он содержит прямые алгоритмические сигналы и не означает наличие Scenario Manager.
